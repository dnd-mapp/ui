# Button

A button starts an action, such as saving a map. It's built after the `Button` component in the `Design system` Figma file.

## When to use

Pick the variant after the weight of the action. The icon slots will follow.

| Variant     | Look                                | Use for                                                        |
| :---------- | :---------------------------------- | :------------------------------------------------------------- |
| `primary`   | The accent fill                     | The one main action in a view, such as "Save map"              |
| `secondary` | A 1px border, with no fill          | Other actions beside the main one, such as "Export map"        |
| `ghost`     | No border and no fill               | Minor actions that should stay quiet, such as toolbar actions  |
| `danger`    | The danger fill, in the `red` scale | Actions that destroy or remove something, such as "Delete map" |

Keep to one `primary` button in a view, so the main action stands out. A `danger` button replaces the `primary` one when the main action destroys something, such as in a dialog that confirms a delete.

Pick the size after the space around the button. Keep the buttons in one row to one size, so they line up.

| Size     | Height | Padding      | Radius      | Text style     | Use for                                                 |
| :------- | -----: | :----------- | :---------- | :------------- | :------------------------------------------------------ |
| `small`  |   32px | `spacing/12` | `radius/4`  | `Label/Small`  | Dense layouts, such as table rows and panel headers     |
| `medium` |   40px | `spacing/16` | `radius/8`  | `Label/Medium` | Most actions, such as the ones in toolbars and dialogs  |
| `large`  |   48px | `spacing/24` | `radius/12` | `Label/Large`  | Actions that lead a sparse view, such as an empty state |

## Usage

Put `dma-button` on a native `button` element, and import `ButtonComponent` into the component that uses it. The content of the element is the label.

```ts
import { Component } from '@angular/core';
import { ButtonComponent } from '@dnd-mapp/ui/components';

@Component({
    selector: 'app-map-toolbar',
    imports: [ButtonComponent],
    template: `<button dma-button type="button" (click)="save()">Save map</button>`,
})
export class MapToolbarComponent {
    save() {}
}
```

Set the variant with the `variant` input. It takes `primary`, `secondary`, `ghost`, or `danger`, and defaults to `primary`. The `ButtonVariants` constant holds the values, and the `ButtonVariant` type is their union.

```html
<button dma-button type="button" variant="danger" (click)="delete()">Delete map</button>
```

Set the size with the `size` input. It takes `small`, `medium`, or `large`, and defaults to `medium`. The `ButtonSizes` constant holds the values, and the `ButtonSize` type is their union.

```html
<button dma-button type="button" variant="ghost" size="small" (click)="rename()">Rename map</button>
```

The button enhances the native element, so it keeps the keyboard support, the form behavior, and the `button` role of the browser. Set `type="button"` unless the button submits a form.

## States

| State    | How it's triggered                               | `primary` and `danger`                                                   | `secondary` and `ghost`                                                      |
| :------- | :----------------------------------------------- | :----------------------------------------------------------------------- | :--------------------------------------------------------------------------- |
| Default  | The button is enabled, and nothing happens to it | The `accent` or `danger` fill, with the `on-accent` or `on-danger` label | No fill, with the `default` label                                            |
| Hover    | The pointer is over the button                   | The `accent-hover` or `danger-hover` fill                                | The `neutral-hover` fill                                                     |
| Pressed  | The button is held down                          | The `accent-pressed` or `danger-pressed` fill                            | The `neutral-pressed` fill                                                   |
| Focus    | The button has keyboard focus                    | An amber ring, 2px outside the button                                    | An amber ring, 2px outside the button                                        |
| Disabled | The native `disabled` attribute is set           | The `disabled` fill and label                                            | No fill, with the `disabled` label, and the `disabled` border on `secondary` |

A `secondary` button keeps its `default` border in every state except Disabled, where the border takes the `disabled` color. A disabled `secondary` or `ghost` button has no fill, because the `disabled` fill matches the hover tint and would look hovered. A disabled `danger` button looks like a disabled `primary` one, because a button that can't act needs no warning color.

The focus ring shows on keyboard focus only, through `:focus-visible`. A disabled button never shows it, because the native `disabled` attribute keeps the button from taking focus. Hover and pressed never apply to a disabled button either.

## Accessibility

- The label is the accessible name of the button, so keep it a short verb phrase, such as "Save map".
- The label passes 4.5:1 against its fill in every variant, and the focus ring passes 3:1 against the page, in both themes.
- A focused `ghost` button shows no fill, so the focus ring alone marks its edge.
- Don't rely on the `danger` color alone to warn the user. Say in the label what the action destroys, such as "Delete map".
- A disabled button leaves the tab order and ignores clicks, like any native button.

## Testing

The `@dnd-mapp/ui/components/testing` entry point has a `ButtonHarness` for tests of the components that use the button. It needs `@angular/cdk`.

```ts
import { TestbedHarnessEnvironment } from '@angular/cdk/testing/testbed';
import { ButtonHarness } from '@dnd-mapp/ui/components/testing';

const loader = TestbedHarnessEnvironment.loader(fixture);
const button = await loader.getHarness(ButtonHarness.with({ text: 'Save map' }));

await button.click();
```

Find a button by its `text`, which takes a string or a regular expression, by whether it's `disabled`, by its `variant`, or by its `size`. The harness can click the button, read its label, its variant, and its size, tell whether it's disabled, and move focus to or away from it.
