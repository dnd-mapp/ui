# D&D Mapp UI

This Storybook shows the components of [`@dnd-mapp/ui`](https://github.com/dnd-mapp/ui), the Angular component library of D&D Mapp. Each component is built after its component in the `Design system` Figma file, and styled with [`@dnd-mapp/design-tokens`](https://github.com/dnd-mapp/design-tokens).

Use the stories to check a component against its Figma component while you build it: every variant, size, and state, in the light and the dark theme. Switch between the themes with the paintbrush in the toolbar.

The components appear in the sidebar as they're added to the library.
